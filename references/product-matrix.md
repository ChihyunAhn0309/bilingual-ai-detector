# Commercial detectors: published methods, languages, and score semantics

Reviewed on **2026-10-03** using official material for 11 products. Descriptions and performance claims from vendors remain vendor claims. This is not a reverse-engineering report or an execution of every product, private architecture, weight set, or threshold. Language support differs from independently established accuracy in that language. Features and interfaces change; prioritize documentation for the version of the supplied report.

## Execution records

Record the product, model/version, plan when known, actual measurement time, submitted source/hash, language, inspected length, extraction/preprocessing, whole/partial coverage, raw values and definitions, completion status, errors, abstention, and truncation. Mark unknown versions as unknown. Do not reuse third-party statistics or a result for an older file with the same name as a measurement of a new manuscript.

## Interpreting reports without detector charges

Since v2, the package interprets saved GPTZero `class_probabilities` only. Live commercial API calls were removed; the legacy command fails before making a request. Free plans, trials, and API credits do not establish a no-charge guarantee. The products above are research/comparison subjects, not services this skill executes or replicates for free.

GPTZero's [official explanation](https://support.gptzero.me/articles/9585228410-how-do-i-interpret-burstiness-or-perplexity) states that it has not used perplexity/burstiness since autumn 2023. Reproducing those older concepts does not implement the current service. Version changes such as the [GPTZero 4o announcement on 2026-09-24](https://gptzero.me/news/introducing-gptzero-4o/) also prevent historical comparisons from being presented as current-version results.
