# GPTZero 등과의 성능 비교

확인일: 2026-10-03. 기능의 충실도와 탐지 정확도를 분리한다. ‘상세한 설명이 있다’는 사실은 정확도가 높다는 증거가 아니다. 이 스킬은 GPTZero 모델을 복제하지 않는다.

## 추가 API 비용 없이 재계산한 공개 결과

[Epoch AI의 2026년 7월 평가](https://epoch.ai/data-insights/ai-detectors-false-negatives)와 [공개 결과 저장소](https://github.com/jaeholee-brown/ai-text-detectors/tree/3f5ed200e212ef5ca957b6f5675d99ed29ff3c3c)를 사용한다. 99명 저자의 영어 글에서 인간 495개, 단순 프롬프트 AI 297개, 작가 문체 모방 AI 297개를 비교했다. 세 장르는 블로그·과학 글·소설이다. 사용자 글을 보내거나 상용 탐지기를 새로 실행하지 않고 저장된 1,089행의 verdict를 재집계했다.

| 탐지기와 당시 버전 | 인간 글 오탐 | 기본 생성 AI 미탐 | 문체 모방 AI 미탐 |
| --- | ---: | ---: | ---: |
| GPTZero 2026-05-11-base | 0/495 (0%) | 2/297 (0.67%) | 32/297 (10.77%) |
| Pangram 3.3.2 | 0/495 (0%) | 0/297 (0%) | 30/297 (10.10%) |
| Originality Turbo 3.0.2 | 19/495 (3.84%) | 1/297 (0.34%) | 53/297 (17.85%) |

원 평가의 엄격한 규칙: 순수 AI 표본에서 AI-only 판정만 검출로 인정하고 Mixed를 미탐으로 센다. 인간 표본에서 Mixed는 오탐이다. 현재 최신 모델·한국어·모든 humanizer 성능을 뜻하지 않는다. 0/495도 실제 오탐률 0%를 보장하지 않는다. 저자별 종속성이 있으며 학습 데이터 중복 가능성도 별도 검토 대상이다.

원문에 있는 GPTZero의 perplexity/burstiness 설명은 [현행 공식 안내](https://support.gptzero.me/articles/9585228410-how-do-i-interpret-burstiness-or-perplexity)와 다르다. 여기서는 공개 측정값과 버전만 재사용하며 그 오래된 방법 설명을 채택하지 않는다.

```text
python scripts/benchmark_epoch.py --cache work/epoch-public --out work/public-comparison.json
```

## 이 스킬과 비교할 때

| 항목 | 이 스킬 v2 | GPTZero 등 상용 서비스 |
| --- | --- | --- |
| 추가 탐지 서비스 요금 | 로컬 분석·공개 다운로드·기존 보고서만 사용 | 해당 서비스/계정 조건에 따라 다름; 이 스킬에서 호출 금지 |
| 한국어 상세 설명 | 원문 전체 검토·정확한 위치·판단 이유·대안 설명 | 제품별 설명 기능/언어 범위가 다름 |
| 영어 확률 | 선택적 무료 로컬 네 범주 모델; 범위·보정 한계 명시 | 서비스가 반환한 네이티브 결과 |
| 한국어 확률 | v3 내장 문자 분류기 + 별도 sigmoid 보정; 장르·분포 한계 명시 | 지원 제품의 원래 출력은 저장된 보고서로 해석 가능 |
| 설명 검증 | 원문 해시·인용·좌표·검토율 자동 검사 | 제품별 구현에 따름 |
| 모델 영향 측정 | 로컬 문단 삭제 전후 민감도, 조건/한계 표시 | 공개된 해당 기능과 모델 버전에 따름 |
| 범용 정확도 우위 | 입증되지 않음 | 언어·버전·데이터별 공정한 비교 필요 |

LLM의 문체 설명과 분류 점수가 불일치하면 둘을 그대로 표시한다. 문체 근거 개수로 모델 점수를 보정하거나 재작성 후 더 낮은 점수를 성능 개선으로 부르지 않는다.

## 재현 가능한 무료 로컬 pilot

```text
python scripts/benchmark_epoch.py --cache work/epoch-public --model-dir models/tropa-mini --authors-per-genre 4 --out work/local-pilot.json
```

seed 20261003으로 장르당 4명(총 12명)을 먼저 선택하고, 저자당 인간 원문 하나와 같은 생성모델의 기본/모방 글 하나씩, 총 36개를 사용한다. 분류를 보기 전에 선택한다. 모델별 학습 데이터와의 중복은 알 수 없으므로 독립 holdout이라고 주장하지 않는다.

이 pilot의 목표는 **AI 관여 유무**로, GPTZero/Pangram의 Mixed는 AI로 센다. 따라서 위 원 평가의 AI-only 기준 표와 직접 섞지 않는다. 로컬 점수는 전체 입력을 덮는 겹친 창들의 AI 관여 점수 평균이다. 이는 평가용 통계이며 보정된 문서 확률이 아니다. 임계값 0.5와 모델 카드의 0.9755912190656111을 사전 고정해 둘 다 보고하고, 좋은 결과만 선택하지 않는다. 실패·검토 범위·동일 문서 교집합을 함께 기록한다.

pilot을 실행하지 않았거나 실패했다면 결과가 없다고 적는다. 실행 결과를 보지 않고 예상 수치를 쓰지 않는다. 작은 표본에서의 우위나 열위를 한국어·최신 GPTZero·범용 성능 순위로 일반화하지 않는다.

## 이번에 실행한 36개 영어 pilot 결과

36개 모두 실행 완료, 실패 0개. 같은 문서·같은 AI 관여 목표의 결과다. 로컬 모델은 이번에 실제 실행했고 상용 모델은 원 저장소의 과거 verdict를 읽었다. 36개 모두 단일 창에 들어가 이번 pilot에서 창 평균의 영향은 없었다.

| 모델·사전 고정 임계값 | 맞힌 글 | 표본 정확도 | 인간 오탐 | 기본 AI 미탐 | 문체 모방 AI 미탐 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 무료 로컬 모델, 0.5 | 30/36 | 83.33% | 3/12 | 0/12 | 3/12 |
| 무료 로컬 모델, 모델 카드 임계값 | 28/36 | 77.78% | 2/12 | 0/12 | 6/12 |
| GPTZero 2026-05-11-base | 35/36 | 97.22% | 0/12 | 0/12 | 1/12 |
| Pangram 3.3.2 | 36/36 | 100% | 0/12 | 0/12 | 0/12 |
| Originality Turbo 3.0.2 | 34/36 | 94.44% | 0/12 | 0/12 | 2/12 |

재현용 [수치·표본 목록·해시](benchmark-results.json)를 제공한다. 각 조건 12개뿐이며 저자별 자료가 연결되어 있으므로 일반적 정확도 추정이나 순위 확정에 부족하다. 특히 무료 모델은 높은 점수로 인간 글을 오탐한 사례가 있어 실험용 보조 점수로 제한했다. 기본 생성 AI에는 강했지만 인간 문체 모방에는 약했다. 임계값을 높이면 오탐 한 건을 줄이는 대신 모방 AI 미탐이 세 건 늘었다. 이 변경을 성능 향상으로 포장하지 않았다.

**GPTZero보다 낫다는 결론은 나오지 않았다.** 설명·좌표·원문 검토 기능을 보강한 것과 분류 정확도 향상은 다른 주장이다. 문체 신호를 임의로 더해 이 결과를 뒤집지 않는다. v3에서는 별도의 한국어 분류기를 학습·평가했다. 아래 한국어 결과와 이 영어 pilot은 직접 비교할 수 없다.

## 개선과 검증의 경계

v2의 확실한 개선은 추가 요금 차단, 전체 문단 검토, 정확한 근거 연결, 허구 인용 거부, 한/영 적용 범위 분리, 미검토 구간 표시, 실제 모델 민감도와 분석자 해석의 분리다. 이 개선의 존재는 코드와 실제 산출물로 확인할 수 있다. 탐지 정확도 개선은 별도의 동일 표본 측정이 필요하다.

한국어 또는 humanizer 대응력을 추가 학습으로 높이려면 무료로 사용할 수 있는 라벨 이력 자료, 저자/주제/원본 그룹 분리, untouched test, 장르·언어별 FPR/미탐과 보정 평가가 먼저다. 새 데이터 없이 임의 앙상블·가중치·확신 수치를 추가하는 것은 검증된 개선이 아니다.


## v3 한국어 실제 학습·평가

[한국어 모델 카드](korean-model.md)의 주제 분리 holdout 1,846개에서 정확도 97.51%, 인간 오탐률 0.90%였다. 에세이가 1,714개이며 초록 37개·시 95개의 정확도는 각각 91.89%, 87.37%다. 별도 1,907개 자료로 보정했고 ECE는 0.03648→0.01704, 정확도는 97.72%→97.51%로 변했다. 완벽한 확률이나 정확도 증가를 뜻하지 않는다.

한국어 동일 문서에서 GPTZero를 실행하거나 저장 결과를 확보하지 않았으므로 **한국어에서 GPTZero보다 좋은지는 미측정**이다. 과거 영어 GPTZero 97.22%와 새 한국어 97.51%는 다른 평가여서 순위를 매길 수 없다. 상용 API 요청은 0회다. 범용 글·최신 humanizer의 성능 개선 여부도 별도의 새 평가가 필요하다.
